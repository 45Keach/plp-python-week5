# Week 5 Assignment: Countdown, Guessing Game & Loop Patterns

This repository contains the Week 5 hands-on lab practicing `while` and `for` loops.

- `countdown.py` — asks for a starting number and counts down to 1 before printing "Blast off!".
- `guess_game.py` — runs a number guessing game with high/low hints and an attempt counter.
- `spell_it_out.py` — prints each letter of a word, then prints the letters with position numbers and the total length.
- `screenshots/` — screenshots showing example runs of each program.

## When would you use a while loop instead of a for loop?

I would reach for a `while` loop when I need to repeat something until a condition changes or an event happens, especially when I do not know in advance how many repetitions are needed. A `for` loop is often a better fit when I want to go through a known sequence or range of items.

## How to run

Make sure Python 3 is installed, then run:

```bash
python countdown.py
python guess_game.py
python spell_it_out.py
```
